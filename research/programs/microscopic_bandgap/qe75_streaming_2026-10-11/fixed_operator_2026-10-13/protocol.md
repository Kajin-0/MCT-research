## Sufficient input and native coverage proof

**PROVEN UNDER THE PINNED NC CPU TWO-RANK/ONE-POOL/ONE-GROUP ASSUMPTIONS.**
`vexx_k` constructs a pair density from the trial spinor and the occupied source
spinor, applies the periodic screened Coulomb multiplier and FFTs, contracts
source occupations, and projects back onto the trial's G basis. It never reads
rho(real), vrs, local/nonlocal Hamiltonian or et. These latter fields affect an
SCF trajectory, but this new driver never invokes that trajectory. Ultrasoft,
PAW, localization, GPUs and additional groups are explicitly refused.

The six genuine control `before` packets contain all48 source/trial columns at
each of three irreducible k points, both spin components, full active global G
labels, source occupations at all three k, native q/k/FFT maps and the actual
normalized diagnostic trial probe. `aceinit` reads these same columns from the
native wave buffer. With negrp=1, `transform_evc_to_exx(2)` aliases the buffer,
G maps and coefficients without a separate band redistribution. Eight source
k+q points are generated by `index_xk`, signed `index_sym`, `rir`, and `d_spin`;
all3×8 target/source mappings must be present, and every source index must lie
in1..3. Time reversal uses the same captured signed mapping and native routine.
Padding has no physical G label; all unused padding is set to zero. No active
coefficient, spin, band or phase is modified.

Native weights are recovered exactly from actual control occupations and k
weights(1/8,1/2,3/8). Partial occupations occur only at1/8, in normal range0.1..0.9;
power-of-two multiplication/division is exact here. At3/8 occupations are0/1;
neighbors of3/8 do not divide/round to1, so native WG has a unique double
preimage. Actual decoded values and neighbor checks are retained. WK is checked
against live QE WK before injection; `exxinit` occupation division must produce
bit-identical captured occupation bits. WG also supplies native matcalc energy.

Missing original spin-rotation and Coulomb cache tables are **not invented**.
One targeted stock-arithmetic setup-only capture replays canonical native wave
buffers, constructs the original FFT/symmetry/screened kernel, and stops before
q-buffer allocation/EXX/ACE. This does not repeat control SCF or control action.
The constructors depend only on pinned geometry, mesh, functional, NC flags and
backend/rank layout. Its full actual qdiag layout and rank FFT descriptors must
match the original control. The kernel packet includes full layout, cell/unit
scalars, active rotations/d_spin/rir, working_pool, occupation/WG/WK, screen/
regularization flags, exxdiv and every Coulomb multiplier at each3×8(k,q).
It prewarms the unchanged native cache in the native first-use k/q order.

The streamed member independently constructs these same tables and must match
**all packet bytes** before any source-q generation/exchange. Canonical source,
WG/WK/probe/basis readbacks also must match all bytes at phase8. Every original
active trial/probe coefficient and output basis is checked by the retained
paired comparator. Native Fock, matcalc, ACE Cholesky/update and action arithmetic
are untouched. Diagnostics use the original probe bytes, without renormalizing.
Missing tables, maps, input bytes or records refuse; no tolerance relaxation.
