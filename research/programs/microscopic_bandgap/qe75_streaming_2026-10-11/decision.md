# Decision — stop at the software/runtime boundary

**GO: retain the verified one-q-plane storage candidate.** The lifetime audit
permits lossless q streaming for the prepared fresh CPU/NC/SOC/ACE SCF path.
Small tests and actual source compilation support nominal exchange-buffer
capacity reduction **22 → 2.75 GiB**, with no altered physical inputs or reduced
352-band ACE coverage. A private candidate links; stock QE stays unchanged.

**NO-GO: launch or certify the paired HSE SCF.** This task establishes storage
equivalence under explicit source/path/I/O assumptions. It does not establish
whole-PW MPI/FFT runtime equivalence, full-SCF resource headroom, disk performance
or valid interruption/restart. No SCF/HSE/MPI job is launched. The failed host
remains rejected; Cd is not admitted; historical goal remains BLOCKED unchanged.

The single next engineering gate is **a bounded native stock-versus-streamed
exchange/ACE comparison after checkpoint and disk admission design are resolved**,
using the same physical numerical settings in the comparison. Specify that scope
before execution; reject any mismatch or unsafe measured resources. This is a
recommendation, not a queue or fresh run authorization. The previous staged host
authorization is not silently reused with changed checkpoint behavior.

No RAM purchase is necessary to retain this candidate. Existing disk may support
one uncompressed store, conditionally on actual padding and output reserve; no
promise of successful full-SCF fit is made. An out-of-core algorithm shifts the
resource obligation to I/O and does not erase it. A duplicate full checkpoint
would make current disk inadequate; ownership-transfer checkpoint design avoids
that duplication only if correctly implemented and verified.

This is an engineering checkpoint, not a new HgCdTe theorem, no-fit prediction,
material validation or novelty claim. Stop here rather than repeat analysis or
launch a speculative native retry. Other R07 negative results and programs remain
unchanged. MCT research branch receives this package; no DFT commit or main merge.
