# Exact acceptance boundary and reproduction

**Source/build vs component vs native are separate conditions.** The new
sources are prospective and unreleased. An ELF that links is not evidence of
correct MPI execution, complete owner lifecycle, memory benefit or chemistry.

1. Native begin: true mp_world size2, actual rank, fresh252byte R07S packet,
   same new JOB/PROFILE/nonce/invocation. Actual socket peer UID/pidfd/start/
   cgroup/ELF/argv must match. Both begins are received before either grant.
2. Native final: all12 actions, all five action arrays and density/potential/
   FFT/G headers written; FLUSH/INQUIRE/CLOSE IOSTAT succeeds. All-rank barrier
   precedes final. Both live finals, correct particular registered process,
   closed regular-file extents and immutable hashes, real packet readback and
   current resource gates precede success reply. Final is not an exit receipt.
3. Active inventory: every live owned actor's FD inventory is required. Whole
   task AND individual FD disappearance/denial routes to strict identity
   predicates; any live rank denial is FATAL. Unknown actors/errors/paths,
   source changes or incomplete packets refuse. Failure is absorbing.
4. Retired rank: BOTH prior actual live finals and that PARTICULAR retained
   process pidfd's exit readiness are necessary for TERMINAL_PENDING only.
   Three-second deadline stays inside the overall600s checks. Live remaining
   actor/retained-tree/host-pressure accounting continues. No JOBDONE, missing
   PID, zombie state, JSON or caller boolean proves exit.
5. Outside terminal: both rank pidfds dead, foreground manager exit0, retained
   identical unit/invocation/exit0/no restart/no delegation, original empty
   cgroup inode or its verified absence, no tasks/descendants, fresh source/
   packet readback, complete output accounting and durable outside result.
   A lost/oversized/incomplete log is an additional refusal; text never grants.

**Actual component observations:** real two compiled NON-MPI peers, socket
pidfds and flags0 process pidfds; live EACCES via ONLY a disposable child's
dumpability; actual exit and descriptor reuse; actual truncated and2MiB
allocated output files. Tests drive production owner.service, Protocol and
Account, not just a copied mathematical predicate. Every child was reaped.

**Explicit modeled conditions:** no systemd service/cgroup hard limit was
created. Positive terminal snapshots and the tiny NON_MPI_FIXTURE reader
were mocked; native reader.decode rejects that fixture. Native C/Fortran
binary was linked but not run, and full owner.run was not exercised. Thus
the tested component graph is implemented, but **full production integration
qualification is BLOCKED**. Setup/ref acquisition, stop/cancel/crash and memory
outside the unit still need independent evidence. Private pending latch is
not a host-wide exclusion theorem or a substitute for that evidence.

Resource controls remain12GiB cgroup memory, swap0, tasks12,600s, available host
RAM4GiB/disk10GiB and14GiB owned aggregate retained output. Sampled block/inode/
deleted-open generation accounting and a stated metadata allowance are not a
continuous quota. Between-sample bursts/external writers remain unbounded by
RLIMIT_FSIZE, which is per file. No inode quota/reservation was newly created.
`resource_audit.json` names the required unknowns rather than guessing them.

Reproduce from MCT, bytecode disabled and BLAS threads1, with the existing DFT
venv interpreter (read-only libraries) or an environment with numpy/scipy/h5py:

    python assemble_account.py
    python test_integration.py
    python audit_and_verify.py

Use the script paths in this directory. test_integration creates only fresh
disposable MCT scratch with retained compiled worker provenance; it never
calls owner.run or invokes systemd/mpirun/pw.x. Its failures are not retried
native experiments. build.py is a FRESH-build-only script; existing build2
refuses overwrite. Existing native ELF can be verified without executing it.
Do not delete old builds/evidence to force a rerun. Frozen v1 records/input
remain as compile-only history; v2 adds correct service INVOCATION_ID fallback.

The accepted old PBE saves/reference remain private; public hash manifests are
not downloadable wavefunctions or evidence of a new physical measurement.
