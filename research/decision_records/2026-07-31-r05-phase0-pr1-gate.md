**Date:** 2026-07-31

**Controlling issue:** #390  
**Decision:** `GO_MINIMAL_ORACLE_RESTRICTED`  
**Not a final Phase 0 decision:** `ACTIVATE_R05` remains blocked

## 1. What was tested

PR 1 tested whether a bounded minimal numerical oracle is scientifically justified before implementing disorder propagation.

The gate included:

- repository dependency and convention audit across R02, R03, and R04;
- claim-level random-mass Dirac and HgCdTe disorder prior-art screening;
- signed-gap, mass, velocity, unit, basis, and degeneracy conventions;
- source-quality-ranked HgCdTe parameter envelope;
- analytical homogeneous, scalar-null, short-correlation, long-correlation, massless, large-mass, and domain-wall limits;
- experimental-resolution and full-Kane necessity screening;
- explicit activation and termination criteria.

## 2. Why it was tested

The issue is not whether correlated random mass can affect a Dirac DOS in principle. That is established in generic 1D and 2D literature.

The decision-changing question is narrower:

> Can a finite-range HgCdTe/Kane mass field produce a converged, experimentally resolvable low-energy signature that is not reproduced by an incoherent scalar mixture with the identical one-point mass distribution?

A minimal oracle can quantify the required dimensionless regime and determine whether any further material work is justified.

### 3.3 Analytical-null gate

For a smooth scalar mass marginal,

\[
\rho_{\rm scalar}(E)
=\frac{|E|P(0)}{\hbar v_K}+O(|E|^3).
\]

For a zero-mean Gaussian mass distribution,

\[
\rho_{\rm scalar}(E)
=
\frac{|E|}{\hbar v_K\sqrt{2\pi}\sigma_M}
\exp\left[-\frac{E^2}{4\sigma_M^2}\right]
I_0\left(\frac{E^2}{4\sigma_M^2}\right).
\]

These provide exact low-energy and full zero-mean references for the numerical null.

The long-correlation LDA reduces exactly to the scalar mixture at leading order. Therefore any non-scalar effect must be traced to coherent gradients, sign-changing interfaces, or another explicitly identified nonlocal mechanism.

## 4. Assumptions

The PR 2 oracle is restricted to:

```text
one spatial dimension
two-component symmetric Dirac Hamiltonian
M = Eg/2
constant v_K
Gaussian primary marginal
Gaussian primary covariance
periodic and antiperiodic boundaries
Fourier pseudospectral ultraviolet regularization

```

The result is a mechanism and threshold benchmark, not a quantitative bulk HgCdTe prediction.

## 6. Frozen effect-size and resolution protocol

Primary dimensionless energy interval:

\[
\mathcal E: |\varepsilon|\le1,
\qquad
\varepsilon=E\xi/(\hbar v_K).
\]

Diagnostic plotting interval:

\[
|\varepsilon|\le2.
\]

Primary integrated statistic:

\[
\Delta_1=
\frac{
\int_{\mathcal E}dE\,
|\rho_{\rm corr}-\rho_{\rm scalar}|
}{
\int_{\mathcal E}dE\,\rho_{\rm scalar}+\epsilon_1
}.
\]

Secondary statistic:

\[
\Delta_\infty=
\max_{E\in\mathcal E}
\frac{|\rho_{\rm corr}-\rho_{\rm scalar}|}
{\rho_{\rm scalar}+0.05\max_E\rho_{\rm scalar}}.
\]

Apply Gaussian experimental-resolution convolutions with dimensionless widths:

```text
delta_epsilon_exp = [0.10, 0.25, 0.50, 1.00]
```

The provisional decision kernel is

```text
delta_epsilon_exp = 0.25.
```

This corresponds to physical resolution

\[
\delta E_{\rm exp}=0.25\hbar v_K/\xi.
\]

Examples:

```text
xi = 100 nm -> delta_E_exp = 1.76 meV
xi = 500 nm -> delta_E_exp = 0.352 meV
xi = 1000 nm -> delta_E_exp = 0.176 meV
```

## 7. Sampling and convergence requirements

Pilot sampling:

```text
64 realizations per selected parameter point
4 independent seed batches of 16
```

Production sampling at points near a decision boundary:

```text
minimum 256 realizations
increase to 512 only if the confidence interval can change the gate
```

Required uncertainty and drift:

```text
standard error of Delta_1 <= 0.02 absolute
finest-grid discretization drift <= 0.03 absolute
largest-box finite-size drift <= 0.03 absolute
scalar-null implementation discrepancy <= 0.01 absolute
paired-spectrum residual <= 1e-10 dimensionless for exact references
Hermiticity residual <= 1e-12 relative
```

A claimed effect must retain its sign and qualitative energy dependence across independent seed batches.

## 8. Restricted activation threshold

A numerical non-scalar effect passes PR 2 only if

```text
minimum converged Delta_1 across accepted numerical variants > 0.10
after delta_epsilon_exp = 0.25 convolution
```

and all uncertainty and null-reference requirements pass.

This threshold authorizes only PR 3 physical screening. It does not activate R05.

## 9. PR 2 stop rules

Return `STOP_NUMERICAL_EFFECT` if:

- the correlated model converges to the scalar null;
- `Delta_1 <= 0.10` after the decision convolution;
- the effect disappears under boundary averaging;
- the effect is explained by unmatched marginals or field normalization;
- finite-size, spacing, ultraviolet, broadening, or seed drift exceeds the effect;
- covariance-family variation reverses the result without a physical explanation.

Return `GO_PHYSICAL_SCREENING` only if a robust effect survives.

## 10. Physical-claim stop rule

Even if PR 2 passes numerically, the HgCdTe physics claim should terminate or be reframed if the effect requires only

```text
g >= 1
```

while no qualifying HgCdTe source supports the corresponding `sigma_M` and `xi` combination.

A useful code and benchmark package without a source-supported material regime should end as

```text
REFRAME_AS_METHOD_BENCHMARK.
```

## 12. PR 1 decision

```text
GO_MINIMAL_ORACLE_RESTRICTED
```

This decision is justified because the oracle is low cost, analytically falsifiable, and capable of determining the minimum required disorder regime. The absence of a qualifying HgCdTe correlation length blocks activation but does not eliminate the value of the threshold benchmark.
